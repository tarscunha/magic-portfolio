summary: "Magic: The Accounting is a fully functional utility app for tracking life totals and game state in Magic: The Gathering's most popular multiplayer format, Commander. As a UX designer with experience that bridges design and code, I generated this entire application using nothing but natural language prompts within Firebase Studio. This project demonstrates how design intent can be transformed into a robust, live product without writing traditional code, showcasing the power of AI-assisted, low-code development. Try It Out!"
